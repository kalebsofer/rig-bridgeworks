Draft the update as $ARGUMENTS, saved to `work/status-update.md`.
Follow `.claude/rules/client-writing.md`.

1. Read `work/fact-register.md`, `work/call-*.md`, the latest analysis in `work/` and the most recent status update in the pack.
2. Open with the overall position, including anything that has changed since the last update and why.
3. Then the decisions needed, each with one owner and a date, then what is next.
4. Stay within an email or 1 to 3 slides, and cut anything the client does not need.
5. List each number with its source file, and have `number-verifier` check them.
6. Show Kaleb the draft with any claims that could surprise someone in the room.

If Kaleb asks for slides, build the deck with the Artifact tool once he has approved the draft, using aggregates only.

Never send it.
